<b>Руководство быстрого старта</b>

Добро пожаловать в Better Mod Loader (BML)! Это руководство поможет вам быстро освоить основные функции BML.

<b>Основное управление группами</b>

* <b>Создание групп</b>: Нажмите кнопку "Добавить группу" для создания новых групп модов.
* <b>Реорганизация групп</b>: Перетаскивайте заголовки групп для изменения их порядка.
* <b>Переименование групп</b>: Дважды щёлкните по именам групп для переименования.
* <b>Категоризация модов</b>: Перетаскивайте моды на группы для быстрой категоризации.
* <b>Логика загрузки</b>: Игра сначала загружает по порядку групп, затем моды внутри каждой группы.

<b>Последовательные группы (порядок загрузки)</b>

* <b>Концепция последовательных групп</b>: Последовательные группы являются ключевыми для определения приоритета загрузки модов, где группы загружаются одна за другой.
* <b>Механизм загрузки</b>: Загрузчик строго следует последовательности: Группа 1 → Группа 2 → Группа 3...
* <b>Управление зависимостями</b>: Размещайте моды с зависимостями в правильном порядке, чтобы гарантировать первоочередную загрузку зависимостей.
* <b>Контроль переопределения</b>: Моды, которым нужно переопределять функции других модов, должны размещаться в более поздних последовательных группах.
* <b>Различие</b>: Последовательные группы фокусируются на "порядке загрузки", а не на простой категоризации.
* <b>Динамическая настройка</b>: Перетаскивайте для настройки позиций последовательных групп; изменения вступят в силу при следующем запуске игры.

<b>Сортировка и операции с модами</b>

* <b>Точная настройка</b>: Используйте кнопки вверх/вниз справа для пошаговой настройки позиций модов.
* <b>Быстрое перемещение вверх/вниз</b>: Двойной щелчок по кнопкам вверх/вниз мгновенно перемещает моды в начало/конец группы.
* <b>Сортировка перетаскиванием</b>: Перетаскивайте моды напрямую к целевым позициям для сортировки.
* <b>Пакетные операции</b>: Поддержка активации/деактивации в один клик для текущей группы или всех модов.
* <b>Управление состоянием</b>: Просмотр в реальном времени активированного/деактивированного состояния каждого мода.

<b>Вспомогательные инструменты и режимы</b>

* <b>Быстрый доступ</b>: Правый щелчок на модах для прямого открытия их папок или страниц Steam Workshop.
* <b>Режим разработчика</b>: При активации можно просматривать и управлять следующими ключевыми папками:
  - <b>Папка модов</b>: Содержит все загруженные файлы модов
  - <b>Папка постоянных данных игры</b>: Файлы сохранений и данные игры
  - <b>Папка конфигурации</b>: Файлы конфигурации BML и других плагинов
* <b>Решение проблем</b>: При возникновении проблем с модами быстро находите релевантные файлы через режим разработчика.

<b>Функции загрузки и многоязычная поддержка</b>

* <b>Загрузка модов</b>: Поддержка прямой загрузки ваших модов на Steam Workshop, упрощая процесс публикации.
* <b>Многоязычные описания</b>:
  - Поддержка создания подробных описаний на нескольких языках для ваших модов
  - Предоставление локализованных введений в функции для пользователей разных языков
  - Автоматическое отображение описаний на основе настроек языка Steam пользователей
* <b>Обновления многоязычных заголовков</b>:
  - Поддержка установки различных заголовков языков для модов
  - Настройка уникальных имен модов для каждой языковой версии
  - Улучшение узнаваемости среди пользователей из разных регионов
* <b>Система тегов</b>:
  - Добавление функциональных тегов к модам (например, Интерфейс, Геймплей механики, Новый контент)
  - Добавление типовых тегов (например, Улучшение, Патч, Пакет расширения)
  - Добавление тегов совместимости (например, Совместимость с мультиплеером, Требования к конкретной версии)
  - Теги помогают пользователям быстро фильтровать и находить интересующие их моды

<b>Советы по использованию</b>

* <b>Предложения по группировке</b>: Категоризируйте по функции (например, Улучшение UI, Геймплей механики, Расширение контента)
* <b>Оптимизация производительности</b>: Размещайте крупные контентные моды первыми, небольшие утилитарные моды последними
* <b>Проверка совместимости</b>: Используйте последовательные группы для обеспечения совместимости и правильного порядка загрузки между модами
* <b>Многоязычная стратегия</b>: Добавляйте многоязычную поддержку к модам для расширения аудитории
* <b>Оптимизация тегов</b>: Используйте точные теги для улучшения видимости и количества загрузок модов
* <b>Регулярное обслуживание</b>: Регулярно проверяйте обновления модов и удаляйте неиспользуемые моды
